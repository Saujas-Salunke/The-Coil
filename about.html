About The Coil

A fictional newsroom, built for a very real lesson in technical SEO.

The Coil is not a real news publication. Every headline, byline, quote, and "investigation" on this site was written for a college assignment exploring how search engines discover, understand, and rank websites. Nothing here should be mistaken for factual reporting — including this sentence, which is, factually, the truest thing on the site.

Why a fake newsroom?

Search engine optimization is easiest to demonstrate on a site that actually behaves like the kind of website SEO techniques are built for: one with articles, categories, metadata, and a reason for pages to link to each other. A parody news site gave this project real content to work with, without requiring any real news.

What this project demonstrates

Behind the humor, this site is a working example of the following technical SEO concepts:

  • Unique page titles and meta descriptions on every page
  • Semantic HTML5 elements (header, nav, main, article, section, aside, footer)
  • A clear, single-H1 heading hierarchy on every article
  • JSON-LD structured data using schema.org's NewsArticle, WebSite, and Organization types
  • Canonical URLs to prevent duplicate-content confusion
  • A complete sitemap.xml listing every indexable page
  • A robots.txt file that allows crawling and points to the sitemap
  • Open Graph and Twitter Card metadata for link previews
  • Descriptive, keyword-conscious internal linking between related articles
  • Responsive, mobile-first layout and accessible navigation

A note on the fiction

All names, quotes, statistics, and events described in The Coil's articles are invented. Any resemblance to real people, coffee purchases, or browser tab counts is purely coincidental — or, in the case of browser tabs, uncomfortably accurate for reasons that have nothing to do with this website.
