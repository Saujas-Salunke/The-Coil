Privacy Policy

Short version: there isn't much to say, but here's the long version anyway.

This is an educational project

The Coil is a static website built for a college assignment about technical SEO. It is hosted as a simple set of HTML, CSS, and JavaScript files with no backend server and no database.

We do not intentionally collect personal information

This site does not use tracking cookies, analytics scripts, or advertising networks. The contact form on this site is a front-end demonstration only: submitting it does not send an email or transmit your information anywhere, and nothing you type into it is stored.

Hosting

This site is hosted on GitHub Pages. Like any web host, GitHub Pages' infrastructure may log basic technical information (such as IP addresses) as part of normal web server operation. That logging is handled by GitHub, not by The Coil, and is governed by GitHub's own privacy policy.

If services are added later

If a real contact-form service, analytics tool, or comment system is ever connected to this site in the future, that service may have its own data collection practices and privacy policy, which would apply in addition to this notice.

Questions

This is a demonstration project rather than a live publication, but if you have questions about how it was built, visit the About page or reach out through the contact page.
